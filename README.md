# 💊 Rx Finder

### Medicine Availability & Price Comparison Platform

**Rx Finder** is a modern, responsive web application designed to help users find medicines, explore nearby pharmacies, compare prices, and manage saved medicines from a single interface.

The application provides an intuitive search experience with location-based pharmacy discovery, medicine filtering, comparison tools, and a clean healthcare-focused user interface.

---

## 🌐 Live Demo

**[Visit Rx Finder](https://rx-finder.netlify.app/)**

---

## ✨ Key Features

### 🔎 Medicine Search

* Search medicines by **medicine name, generic name, or medical condition**.
* Search suggestions for faster navigation.
* View medicine information through an interactive detail panel.

### 💰 Price Comparison

* Compare prices of available medicines.
* Sort results by:

  * Relevance
  * Distance
  * Lowest price
  * Highest price
  * Availability

### 🏪 Pharmacy Discovery

* Explore nearby pharmacies.
* Find pharmacies using location-based search.
* Identify pharmacies operating **24×7**.
* View pharmacy locations based on OpenStreetMap data.

### 📍 Location-Based Search

* Detect the user's location using the browser's **Geolocation API**.
* Manually select a locality when required.
* Filter pharmacy results according to distance.

### 🎛️ Advanced Filters

Filter medicine results based on:

* OTC / Prescription
* Maximum price
* Stock availability
* 24×7 pharmacy availability
* Distance from the selected location

### ⚖️ Medicine Comparison

* Add medicines to the comparison tray.
* Compare selected medicines in one place.
* Easily remove medicines or clear the comparison list.

### 🔖 Saved Medicines

* Save medicines for quick access.
* View all saved medicines from the dedicated **Saved** section.

### 🌙 Theme Support

* Light and dark mode.
* Theme preference can be switched directly from the navigation bar.

### 📱 Responsive Interface

Designed to provide a consistent experience across:

* Desktop
* Laptop
* Tablet
* Mobile devices

## 🚀 Getting Started

### Prerequisites

No backend or additional framework is required to run the current version.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Arushi-20/Rx-Finder.git
```

**2. Navigate to the project**

```bash
cd Rx-Finder
```

**3. Run the application**

Open `index.html` directly in your browser or launch it using **Live Server** in VS Code.

---

## 📍 Location & Pharmacy Data

Rx Finder uses browser-based geolocation for location detection and OpenStreetMap-based data for pharmacy discovery.

Location detection requires the user's browser permission.

Pharmacy information is intended for discovery and reference. Users should verify current pharmacy availability, operating hours, and medicine prices directly with the pharmacy.

---

## ⚠️ Disclaimer

Rx Finder is an informational web application and is **not a medical service**.

Medicine prices, availability, and pharmacy information displayed by the application may not always reflect the latest information.

Always confirm medicine availability, pricing, prescription requirements, and other relevant information with the pharmacy or a qualified healthcare professional.
